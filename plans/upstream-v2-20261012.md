## Blocking follow-up before merge

Upstream's registry migration from 1.0.0 to 2.0.0 takes an access-exclusive lock and drops `executor_public_apps` and `executor_public_scopes`. Cloud invokes it before replacement server deployment; old code still needs these tables. The source explicitly acknowledges old publishes can fail after migration. This violates the repository's online-migration requirement. Do not merge/deploy this draft until the migration has a compatible staged rollout and retained-data, repeat-run and old-server tests on the relevant adapters. No production database has received this migration.

Also complete migration acceptance for the new SDK storage 4.0.12 and the wider upstream changes. The focused tests below do not establish complete release acceptance.
